# 100% Save files

repo ini adalah progres dari game zelda botw yang aku main kan, hanya buat tempat save progres aja, soalnya aku ingin save file ini bisa di gunakan di berbagai patform. siapa tau aku bisa menamatkan 100 persen progres dan bisa kamu mainkan.

I made this repo to back up my Zelda: Breath of the Wild save files from my current playthrough. I want to make these save files usable on any platform—Nintendo Switch, Wii U, or even emulators (like Savage Wind / Ryujinx / Cemu). Hopefully, I can reach 100% completion soon so you can use them too!.

**How to Use**

Wii U/Cemu: Unzip files to `cemu_1.23.1\mlc01\usr\save\00050000\101c9400\user\80000001`, so that option.sav is at `cemu_1.23.1\mlc01\usr\save\00050000\101c9400\user\80000001\option.sav`. For Wii U console, do the same in FTPiiU, except starting from the mlc folder instead of the Cemu folder.

Switch Console: Use Checkpoint Save Manager to load the saves in, it should have a folder it pulls from on the microSD card. (I haven't needed to load saves on Switch in a few months, so I don't remember the exact filepath)

Emulator or native BOTW pc: Look for the file named "save," then put everything that’s inside "save_0" into it.
